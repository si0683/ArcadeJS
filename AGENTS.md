# AGENTS.md — правила для ИИ-агентов

ArcadeJS — фреймворк 2D-игр для уроков с детьми: игры собирает нейросеть по промту, результат — 3 файла (HTML, CSS, JS), библиотека подключается с jsDelivr по тегу (`@1.1.0`).

- Обратная совместимость важнее всего: уроки ссылаются на конкретную версию. Вышедший тег не переписывать; изменения API — только в новой версии (VERSION в arcade.js, ссылки в AI.md/README/tools/build.py, тег `vX.Y.Z`).
- Любое изменение API — сразу в AI.md (справочник для нейросетей: короткий, полный, с примерами) и в README.
- Примеры в `examples/` — 3 файла каждый; `index.html` и `codepen.html` создаёт `python tools/build.py` (руками не править). Пример должен работать с CDN-ссылками.
- Код фреймворка и примеров — чистый JavaScript без сборки и классов, комментарии на русском. Глобально наружу — только `window.Arcade`.
- Проверка: `python -m http.server` в папке, тестовые страницы с локальными `arcade.js`/`arcade.css`; автотест — `Arcade.game.start()` и `Arcade.game.step(1/60)` в цикле (панель браузера часто скрыта, rAF не идёт). В консоли не должно быть ошибок.
- Общий промт урока «Создаём игру» — репозиторий CreateGame01PROMT (D:\02GameBrowser\CreateGame01PROMT).
- PROMPT.md (шаблон промта «любая игра/сайт») создаётся генератором промтов (см. комментарий в начале файла) — руками не править; поменялся API — обнови шпаргалку в генераторе.
