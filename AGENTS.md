# AGENTS.md — rules for AI coding agents

ArcadeJS is a general-purpose browser game framework, distributed via jsDelivr (git tags) and npm (`arcadejs`).

- **Never change a published version.** Projects pin `@x.y.z`; tags are immutable. Changes go into a new version: `VERSION` in arcade.js, `version` in package.json, `@x.y.z` links (README*, AI.md, PROMPT*.md, tools/build.py output), CHANGELOG.md, tag `vX.Y.Z`.
- Any API change must be reflected in **AI.md** (compact, complete, with examples), **arcade.d.ts**, both READMEs and the cheat sheets in **PROMPT.md / PROMPT.ru.md**.
- Code: plain browser JavaScript, no build step, no classes in examples, **English comments**. The only global is `window.Arcade`. Interface strings live in `I18N` (en, ru) — never hard-code UI text.
- Examples (`examples/`) are 3 files each; `index.html`, `codepen.html` and `arcade.mjs` are generated by `python tools/build.py` (it also injects the Kenney sound and sprite lists) — do not edit them by hand. Examples must work from the CDN links.
- Assets: only CC0 or permissive licenses; record every source in THIRD_PARTY.md.
- Testing: serve the folder (`python -m http.server`), use test pages with local `arcade.js`/`arcade.css`; drive games with `Arcade.game.start()` and `Arcade.game.step(1/60)` (rAF may not run in a hidden browser pane). No console errors. Types: compile a sample with `tsc --strict --noEmit`.
- Classroom repos (CreateGame01PROMT, lesson games) pin ArcadeJS 1.1.0 — do not migrate them without the owner's request.
