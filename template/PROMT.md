# PROMT.md — техническое задание для ИИ: 2D-игра

Шаблон для игры на стеке **GameMonsterJS2D**: Vite · Phaser 4 · Tiled · TypeScript.

## Как пользоваться

1. Создайте проект:
   ```bash
   npm create gamemonsterjs2d@latest my-game
   ```
   Этот файл уже лежит в папке проекта. Отдельно его можно скачать по ссылке: https://raw.githubusercontent.com/si0683/GameMonsterJS2D/main/PROMT.md
2. Заполните раздел **«Промт»** ниже:
   - замените всё в `«кавычках-ёлочках»`;
   - отметьте нужное `[x]`;
   - удалите строки, которые не подходят.

   Не знаете, что ответить, — напишите «на усмотрение ИИ».

3. Откройте папку проекта в ИИ-ассистенте (Claude Code, Cursor, Codex, Windsurf и т. п.) и напишите:

   > Прочитай PROMT.md и AGENTS.md и сделай игру по разделу «Промт». Начни с плана и вопросов.

   Если ассистент работает только в чате, вставьте в него текст от `НАЧАЛО ПРОМТА` до `КОНЕЦ ПРОМТА`.

4. Ответьте на вопросы, утвердите план и играйте после каждого этапа: `npm run dev` → http://localhost:5173.

Самое важное — раздел 1 (идея и игровой цикл) и раздел 3 (механики). Чем конкретнее числа (скорость, жизни, время уровня), тем ближе результат к задуманному.

### 7. Технические требования

- Стек не меняй: Phaser 4 + Vite + TypeScript. Matter.js — только через Phaser (`physics.default = "matter"`), звук — только через Phaser. Новые npm-пакеты — только с объяснением, зачем они нужны.
- 60 FPS на среднем телефоне: пулы объектов (`group.get()`), без создания объектов в каждом кадре.
- Экран: `Scale.FIT`, игра видна целиком на любом экране; кнопки на телефоне не перекрывают важное.
- Все числа баланса — в `src/config.ts`, тексты для игрока — на «русском».
- Сцены разделены по смыслу: Preload, Menu, Game, Hud, GameOver…; общее состояние — через `this.registry`.
- Музыка включается после первого нажатия (правило браузеров).
- Сборка работает с GitHub Pages (`base: "./"` уже настроен).

### 8. Как работать

1. Прочитай `AGENTS.md`, `README.md`, код в `src/` и нужные справки в `node_modules/phaser/skills/`.
2. Задай мне до 8 вопросов — только о том, без чего нельзя начать. По остальному прими решения и перечисли их.
3. Покажи план: сцены, сущности, данные уровней, ресурсы, этапы. Жди моего «ок».
4. Сначала сделай **играбельный прототип** главного цикла на простых фигурах, потом остальное. Этапы:
   - этап 1 — прототип: герой, управление, одна механика, победа и поражение;
   - этап 2 — враги, предметы, уровни;
   - этап 3 — меню, HUD, экраны, сохранение;

5. Демо-платформер шаблона замени на мою игру. Ненужные файлы удали.
6. После каждого этапа запускай `npm run build` и исправляй ошибки. Затем коротко напиши, что готово и как проверить: какие клавиши нажать и что должно произойти. Для проверки в режиме разработки есть `window.game`.
7. В конце обнови `README.md`: управление, как добавить уровень в Tiled, где менять баланс, как выложить.

## Пример заполнения (коротко)

> **1.** Раннер «Кот-курьер»: кот бежит по крышам и доставляет пиццу. Похоже на Canabalt, но с монетами и бонусами. Для казуальных игроков, сессия 1–3 минуты, рекорд. Телефон, горизонтально.
> **2.** Компьютер: пробел или ↑ — прыжок, ↓ — подкат. Телефон: тап — прыжок, свайп вниз — подкат.
> **3.** Скорость растёт с 200 до 500 px/с за 2 минуты; двойной прыжок; жизни — 1, магнит для монет на 8 секунд; препятствия — трубы, антенны, голуби.
> **4.** Процедурная генерация из готовых кусков крыш, камера — автоскролл.
> **6.** Пиксель-арт, Kenney CC0, музыка — chiptune.

## Подсказки

- **Начинайте с маленькой игры.** Один уровень и одна механика, которые интересно играть, лучше десяти недоделанных.
- **Баланс подбирайте числами.** Пишите ИИ: «прыжок слишком низкий, увеличь на 20 %».
- **Уровни правьте сами** в [Tiled](https://www.mapeditor.org) — это быстрее, чем объяснять ИИ, где поставить платформу.
- **Нашли баг** — опишите шаги: «на 2-м уровне прыгаю на движущуюся платформу → герой проваливается».
