## 7. Технические требования

- **Площадка публикации (SDK):** [ ] без SDK (сайт, GitHub Pages, itch.io) [ ] Яндекс Игры (`--sdk=yandex`: реклама, облачные сохранения, лидерборд — см. `YANDEX.md`). Все вызовы платформы — только через `platform` из `src/platform`.
- Стек не меняй: Phaser 4 + Vite + TypeScript. Matter.js — только через Phaser (`physics.default = "matter"`), звук — только через Phaser. Новые npm-пакеты — только с объяснением, зачем они нужны.
- 60 FPS на среднем телефоне: пулы объектов (`group.get()`), без создания объектов в каждом кадре.
- Экран: `Scale.FIT`, игра видна целиком на любом экране; кнопки на телефоне не перекрывают важное.
- Все числа баланса — в `src/config.ts`, тексты для игрока — на «русском».
- Сцены разделены по смыслу: Preload, Menu, Game, Hud, GameOver…; общее состояние — через `this.registry`.
- Правила игры (очки, победа, поражение, урон) — функциями в `src/rules.ts` с тестами в `src/rules.test.ts`; сохранения — только через `save` из `src/save.ts`; звук — с учётом громкости из меню (`src/audio.ts`).
- Управление — и с клавиатуры, и на телефоне; без резких вспышек на весь экран.
- Музыка включается после первого нажатия (правило браузеров).
- Сборка работает с GitHub Pages (`base: "./"` уже настроен).

## 8. Как работать

1. Прочитай `AGENTS.md`, `README.md`, `RECIPES.md`, код в `src/` и нужные справки в `node_modules/phaser/skills/`.
2. Задай мне до 8 вопросов — только о том, без чего нельзя начать. По остальному прими решения и перечисли их.
3. Покажи план: сцены, сущности, данные уровней, ресурсы, этапы. Жди моего «ок».
4. Сначала сделай **играбельный прототип** главного цикла на простых фигурах, потом остальное. Этапы:
   - этап 1 — прототип: герой, управление, одна механика, победа и поражение;
   - этап 2 — враги, предметы, уровни;
   - этап 3 — меню, HUD, экраны, сохранение;
   - этап 4 — графика, анимации, звук, эффекты;
   - этап 5 — баланс, телефон, полировка.
5. Демо-платформер шаблона замени на мою игру. Ненужные файлы удали.
6. После каждого этапа запускай `npm run check` (линтер, типы, тесты, сборка) и `npm run test:e2e` (игра в браузере) и исправляй ошибки. Новое правило — с тестом, новая основная механика — с шагом в `e2e/game.spec.ts`. Затем коротко напиши, что готово и как проверить: какие клавиши нажать и что должно произойти. Для проверки в режиме разработки есть `window.game`.
7. В конце обнови `README.md`: управление, как добавить уровень в Tiled, где менять баланс, как выложить.
