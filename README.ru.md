# GameMonsterJS2D

**Стартер 2D-игры для браузера одной командой:** Vite · Phaser 4 · Tiled · TypeScript.

[English](README.md) · [Сайт](https://si0683.github.io/GameMonsterJS2D/)

```bash
npm create gamemonsterjs2d@latest my-game
cd my-game
npm run dev
```

Пока пакета нет в npm, запускайте с GitHub: `npx github:si0683/GameMonsterJS2D my-game`.
Ключи: `--no-install`, `--no-git`. Нужен Node.js 20.19+.

## Что внутри

| | |
|---|---|
| [Vite](https://vite.dev) | сервер разработки с мгновенным обновлением и сборка |
| [Phaser 4](https://phaser.io) | сцены, камера, спрайты, ввод, анимации, тайлмапы, звук; физика **Arcade** по умолчанию, **Matter.js** встроен |
| [Tiled](https://www.mapeditor.org) | уровень — карта Tiled (`.tmj`): рисуйте тайлы, ставьте монеты и врагов |
| TypeScript | строгие типы |

А ещё готовый платформер (бег, прыжки, монеты, слизни, шипы, вода, флаг), меню и счёт, кнопки для телефона, бесплатная графика Kenney (CC0), `AGENTS.md` для нейросетей и выкладка на GitHub Pages.

Matter.js и Howler.js специально не ставятся отдельно: Matter.js уже внутри Phaser, звук у Phaser свой.

## Проект через ИИ

[PROMT.md](https://raw.githubusercontent.com/si0683/GameMonsterJS2D/main/PROMT.md) — готовый промт-ТЗ для ИИ-ассистента (Claude Code, Cursor, Codex, ChatGPT…). Весь файл — это промт:

1. Откройте ссылку, выделите всё (Ctrl+A) и скопируйте (Ctrl+C). Тот же файл лежит в папке каждого нового проекта.
2. Замените `«…»` своими данными, отметьте нужное `[x]`, лишнее удалите. Можно и не заполнять — ИИ задаст вопросы.
3. Вставьте в ИИ. Или положите файл в папку проекта и напишите ассистенту: «Прочитай PROMT.md и сделай по нему игру».

Пример заполнения (коротко):

> **1.** Раннер «Кот-курьер»: кот бежит по крышам и доставляет пиццу. Похоже на Canabalt, но с монетами и бонусами. Для казуальных игроков, сессия 1–3 минуты, рекорд. Телефон, горизонтально.
> **2.** Компьютер: пробел или ↑ — прыжок, ↓ — подкат. Телефон: тап — прыжок, свайп вниз — подкат.
> **3.** Скорость растёт с 200 до 500 px/с за 2 минуты; двойной прыжок; жизни — 1, магнит для монет на 8 секунд; препятствия — трубы, антенны, голуби.
> **4.** Процедурная генерация из готовых кусков крыш, камера — автоскролл.
> **6.** Пиксель-арт, Kenney CC0, музыка — chiptune.

Подсказки:

- **Начинайте с маленькой игры.** Один уровень и одна механика, которые интересно играть, лучше десяти недоделанных.
- **Баланс подбирайте числами.** Пишите ИИ: «прыжок слишком низкий, увеличь на 20 %».
- **Уровни правьте сами** в [Tiled](https://www.mapeditor.org) — это быстрее, чем объяснять ИИ, где поставить платформу.
- **Нашли баг** — опишите шаги: «на 2-м уровне прыгаю на движущуюся платформу → герой проваливается».

## Разработка репозитория

```bash
cd template && npm install && npm run dev
npm pack   # затем: npx ./create-gamemonsterjs2d-<v>.tgz test
```

Версии до 3.0.0 были CDN-библиотекой GameMonsterJS (`gamemonster.js`, бывший ArcadeJS). Их теги остаются на jsDelivr.
