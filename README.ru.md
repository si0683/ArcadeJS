# GameMonsterJS2D

**Стартер 2D-игры для браузера одной командой:** Vite · Phaser 4 · Tiled · TypeScript.

[English](README.md) · [Сайт](https://si0683.github.io/GameMonsterJS2D/)

```bash
npm create gamemonsterjs2d@latest my-game
cd my-game
npm run dev
```

Пока пакета нет в npm, запускайте с GitHub: `npx github:si0683/GameMonsterJS2D my-game`.
Ключи: `--template=<жанр>`, `--sdk=<площадка>`, `--no-install`, `--no-git`. Нужен Node.js 20.19+.

## Что внутри

|                                    |                                                                                                               |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| [Vite](https://vite.dev)           | сервер разработки с мгновенным обновлением и сборка                                                           |
| [Phaser 4](https://phaser.io)      | сцены, камера, спрайты, ввод, анимации, тайлмапы, звук; физика **Arcade** по умолчанию, **Matter.js** встроен |
| [Tiled](https://www.mapeditor.org) | уровень — карта Tiled (`.tmj`): рисуйте тайлы, ставьте монеты и врагов                                        |
| TypeScript                         | строгие типы                                                                                                  |

А ещё готовый платформер (бег, прыжки, монеты, слизни, шипы, вода, флаг), меню и счёт, кнопки для телефона, бесплатная графика Kenney (CC0), `AGENTS.md` для нейросетей и выкладка на GitHub Pages.

Matter.js и Howler.js специально не ставятся отдельно: Matter.js уже внутри Phaser, звук у Phaser свой.

## Жанры

```bash
npm create gamemonsterjs2d@latest my-game                         # платформер (по умолчанию)
npm create gamemonsterjs2d@latest my-game -- --template=topdown   # вид сверху: ходьба, рывок, враги-преследователи
```

Жанр меняет только сцену уровня, сущности и карты; меню, уровни, сохранения, эффекты, SDK и тесты — общие.

## Готовые системы игры

Все включаются и выключаются флагами `FEATURES` в `src/config.ts`; числа баланса, список уровней и тексты — в `content/*.json`:

- **Уровни:** список в `content/levels.json`, выбор уровня со звёздами, открытие по порядку, карта грузится при старте уровня.
- **Механики Tiled:** чекпоинты, пружины, движущиеся платформы, доски, сквозь которые запрыгиваешь снизу, подсказки обучения, свойства объектов (скорость врага, путь платформы).
- **Мета-игра:** достижения со всплывающими окнами, ежедневная награда с серией дней, копилка монет, удалённый конфиг баланса.
- **Настройки:** звук, музыка, эффекты, язык, полноэкранный режим, кнопки или джойстик на телефоне, переназначение клавиш; «поверните телефон», безопасные зоны экрана.
- **Звук:** вариации высоты тона, лимит одинаковых звуков, плавная смена музыки, приглушение на паузе, `npm run audio` для сжатия.
- **Выпуск и QA:** офлайн-версия для своего сайта (`npm run build:web`), запись и воспроизведение прохождений (F7/F8), скриншотные тесты экранов, тест FPS на «слабом телефоне» (`npm run test:perf`).

## Ощущение от игры и профессиональные инструменты

- **Движение, которое прощает:** разгон и торможение, coyote time, буфер прыжка, высота прыжка от длительности нажатия, быстрое падение — чистые функции с тестами в `src/movement.ts`, числа в `content/balance.json`.
- **«Сочность»:** пыль, искры, всплывающие «+1», сплющивание и растяжение, белая вспышка при уроне, стоп-кадр при ударе, тряска, камера с взглядом вперёд (`src/fx.ts`).
- **Фильтры Phaser 4:** виньетка, цветокоррекция и светящийся слой для монет (`src/look.ts`); переходы между сценами с затемнением. Настройка «Эффекты» выключает резкие эффекты (доступность, слабые устройства).
- **Управление действиями:** клавиатура, геймпад и тач через один `Controls` (`src/input.ts`); пауза и меню работают с любым из них.
- **Структура для больших игр:** сущности в `src/entities/`, автомат состояний для героя и врагов.
- **Инструменты разработчика в `npm run dev`:** F1 — панель (FPS, состояние героя, события), F2 — ползунки баланса ([Tweakpane](https://tweakpane.github.io/docs/)) с копированием чисел в конфиг, F3 — хитбоксы, F4 — бессмертие, F6 — пройти уровень. В сборку для игроков не попадают.
- **Ассеты и бюджет:** `npm run atlas` упаковывает спрайты в атлас, анимации из Aseprite грузятся напрямую, `npm run size` следит за размером сборки.
- **Аналитика:** события `track()` (начало и конец уровня, смерти с координатами, выход) и отлов ошибок с подключаемыми приёмниками (`src/telemetry.ts`).

## Качество из коробки

- **Проверки:** ESLint + Prettier, строгий TypeScript, модульные тесты [Vitest](https://vitest.dev) (правила игры, сохранения, платформа) и проверка игры в браузере [Playwright](https://playwright.dev): игра грузится без ошибок, меню работает, уровень стартует, герой бегает, прыгает, пауза открывается. Всё вместе — `npm run check`; GitHub Actions запускает его перед каждой публикацией.
- **Надёжная платформа:** ошибки и зависания SDK портала не ломают игру — у вызовов есть лимит времени, неудачная реклама не даёт награду и не вешает игру.
- **Сохранение:** рекорд и настройки в одной записи, старые сохранения читаются; громкость звука и музыки — в меню.
- **RECIPES.md:** пошагово, как добавить врага, уровень, звук, экран, язык, покупку; эффекты, фильтры, Aseprite, атласы, геймпад, настройка баланса в игре, автомат состояний, аналитика, библиотеки под жанр; ассеты, доступность, производительность.

## Студийный уровень

То, что отличает профессиональную разработку: контент отдельно от кода, решения по данным, выпуск куда угодно.

- **Контент как данные:** баланс, уровни и тексты — в `content/*.json`, схемы zod в `content/schema.ts`. Опечатку, число вне диапазона, карту без флага или пропущенный перевод `npm run dev` показывает поверх игры, а сборка останавливается. Формы множественного числа (`{n:монета|монеты|монет}`), тексты через таблицу (`npm run i18n:export` / `i18n:import`, в том числе из Google Таблицы), ассеты отдельного уровня грузятся вместе с его картой.
- **Аналитика:** тепловая карта смертей на уровне (F9), A/B-тесты (`src/experiments.ts`, варианты баланса — из удалённого конфига), ошибки в Sentry/GlitchTip со стеком и версией сборки (без 70 КБ SDK), Яндекс Метрика. Всё включается ключами в `.env`.
- **Свой игровой сервер** (`server/`, без зависимостей, есть Dockerfile): отчёт с воронкой по уровням, удержанием D1/D7, A/B-тестами и ошибками; лидерборд, который отклоняет невозможный результат и хранит запись каждого рекорда (`npm run verify` проигрывает её заново); облачное сохранение и код переноса на другое устройство.
- **Выпуск:** `npm run portal` проверяет требования модерации площадок (архив, пути, прокрутка, звук в скрытой вкладке, язык); itch.io по тегу версии (GitHub Actions + butler); Android через Capacitor (`MOBILE.md`); ПК и Steam через Electron с достижениями Steam (`DESKTOP.md`); проверка каждого pull request с готовой сборкой.
- **Арт и звук:** растровый шрифт с кириллицей из любого CSS-шрифта (счёт в HUD), динамическое освещение тёмных уровней одной строкой в `levels.json`, аудиоспрайты без ffmpeg (`npm run audio:sprite`), автоэкспорт из Aseprite (`npm run art -- --watch`).
- **Архитектура и тесты:** типизированные события (`src/events.ts`): уровень сообщает, что произошло, а аналитика и сервер слушают. Повторяемая случайность (`src/random.ts`). Эталонные прохождения: записи проигрываются покадрово с шагом 1/60 с, итог сверяется до сотых пикселя (`npm run test:golden`). Версия сборки видна в меню.
- **Доступность:** цвета для дальтоников (протанопия, дейтеранопия, тританопия) и контрастный режим, субтитры звуков, скорость игры 100/80/60 %, помощь (+2 жизни и пропуск уровня).

## SDK платформы

Установщик спрашивает, под какую площадку собирать. Можно указать сразу:

```bash
npm create gamemonsterjs2d@latest my-game -- --sdk=none         # без SDK — обычная веб-сборка (по умолчанию)
npm create gamemonsterjs2d@latest my-game -- --sdk=yandex       # Яндекс Игры
npm create gamemonsterjs2d@latest my-game -- --sdk=vk           # VK Игры (vk.com/games)
npm create gamemonsterjs2d@latest my-game -- --sdk=vkplay       # VK Play (vkplay.ru), собственный JS API
npm create gamemonsterjs2d@latest my-game -- --sdk=crazygames   # CrazyGames
npm create gamemonsterjs2d@latest my-game -- --sdk=poki         # Poki
```

Игра обращается к одному интерфейсу — `platform` в `src/platform/`: запуск, «игра готова», начало и конец геймплея, реклама (полноэкранная и за награду), сохранения, лидерборд, покупки, язык, пауза. SDK меняет только реализацию; код игры не меняется. Ошибки и зависания SDK перехватывает `guard()` — игра не ломается.

| SDK          | Реклама              | Покупки                       | Облачные сохранения | Лидерборд | Файл с инструкцией |
| ------------ | -------------------- | ----------------------------- | ------------------- | --------- | ------------------ |
| `none`       | —                    | только в `npm run dev` (тест) | localStorage        | —         | —                  |
| `yandex`     | ✔                    | ✔                             | ✔                   | ✔         | `YANDEX.md`        |
| `vk`         | ✔                    | нужен свой сервер             | ✔                   | —         | `VK.md`            |
| `vkplay`     | если включит VK Play | окно оплаты, цены в игре      | через свой сервер   | —         | `VKPLAY.md`        |
| `crazygames` | ✔                    | Xsolla, для одобренных игр    | ✔                   | —         | `CRAZYGAMES.md`    |
| `poki`       | ✔                    | —                             | localStorage        | —         | `POKI.md`          |

**Покупки** — модуль `src/shop.ts`: восстановление купленного при каждом запуске, постоянные и расходуемые товары. Пример — кнопка «Убрать рекламу» в меню: показывается только там, где площадка продаёт.

**VK Play** (vkplay.ru) — через собственный [JS API площадки](https://documentation.vkplay.ru) (`--sdk=vkplay`), без посредников: `mailru.core.js`, вход и регистрация игрока, окно оплаты `paymentFrame`. Нужен только номер игры (GMRID) в `.env`; без него игра работает как без SDK. Облачных сохранений и лидерборда в JS API нет — их даёт свой игровой сервер (`server/`).

В любом проекте есть `npm run zip`: он собирает `game.zip` с `index.html` в корне для игровых порталов.

## Проект через ИИ

[PROMT.md](https://raw.githubusercontent.com/si0683/GameMonsterJS2D/main/PROMT.md) — готовый промт-ТЗ для ИИ-ассистента (Claude Code, Cursor, Codex, ChatGPT…). Весь файл — это промт:

1. Откройте ссылку, выделите всё (Ctrl+A) и скопируйте (Ctrl+C). Тот же файл лежит в папке каждого нового проекта.
2. Замените `«…»` своими данными, отметьте нужное `[x]`, лишнее удалите. Можно и не заполнять — ИИ задаст вопросы.
3. Вставьте в ИИ. Или положите файл в папку проекта и напишите ассистенту: «Прочитай PROMT.md и сделай по нему игру».

Пример заполнения (коротко):

> **1.** Раннер «Кот-курьер»: кот бежит по крышам и доставляет пиццу. Похоже на Canabalt, но с монетами и бонусами. Для казуальных игроков, сессия 1–3 минуты, рекорд. Телефон, горизонтально.
> **2.** Компьютер: пробел или ↑ — прыжок, ↓ — подкат. Телефон: тап — прыжок, свайп вниз — подкат.
> **3.** Скорость растёт с 200 до 500 px/с за 2 минуты; двойной прыжок; жизни — 1, магнит для монет на 8 секунд; препятствия — трубы, антенны, голуби.
> **4.** Процедурная генерация из готовых кусков крыш, камера — автоскролл.
> **6.** Пиксель-арт, Kenney CC0, музыка — chiptune.

Подсказки:

- **Начинайте с маленькой игры.** Один уровень и одна механика, которые интересно играть, лучше десяти недоделанных.
- **Баланс подбирайте числами.** Пишите ИИ: «прыжок слишком низкий, увеличь на 20 %».
- **Уровни правьте сами** в [Tiled](https://www.mapeditor.org) — это быстрее, чем объяснять ИИ, где поставить платформу.
- **Нашли баг** — опишите шаги: «на 2-м уровне прыгаю на движущуюся платформу → герой проваливается».
