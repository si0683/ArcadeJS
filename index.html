GameMonsterJS2D
GitHub

Стек для 2D-игры одной командой

Vite + Phaser 4 + Tiled: команда создаёт папку с игрой и ставит все пакеты. Внутри готовый уровень, контент в JSON, тесты и выпуск на площадки, Android и Steam.

Как начать

  1. Установите Node.js 20.19+ · проверить: node -v
  2. Создайте проект
    npm create gamemonsterjs2d@latest my-game
  3. Запустите
    cd my-game && npm run dev

Откроется на http://localhost:5173. Пока пакета нет в npm, вместо шага 2: npx github:si0683/GameMonsterJS2D my-game
