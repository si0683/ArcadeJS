A complete game in 20 lines

Menu, settings, countdown, pause, game over, high score and touch buttons come for free. You only describe what happens in your world.

  1. 1
    Add two lines

    The CSS and the script from the CDN — nothing to install.

  2. 2
    Describe the rules

    setup creates the world, update runs every frame.

  3. 3
    Play it anywhere

    Open the file, drop it on any hosting or paste it into CodePen.

// Catch the fruit, dodge nothing — the classic first game
GameMonster.create({
  title: 'Fruit Drop', emoji: '🍉', world: 'sky',
  lives: 3, buttons: ['left', 'right'],

  setup(game) {
    game.data.hero = game.add({ emoji: '🧺', x: 400, y: 540, size: 70, inside: true });
    game.every(0.7, g => g.add({
      emoji: g.pick(['🍎', '🍌', '🍇']),
      x: g.rand(40, 760), y: -30, vy: 220,
      tag: 'fruit', removeOffscreen: true
    }));
  },

  update(game) {
    const hero = game.data.hero;
    hero.vx = game.key.left ? -500 : game.key.right ? 500 : 0;
    const fruit = game.hitAny(hero, 'fruit');
    if (fruit) { fruit.remove(); game.addScore(1, fruit.x, fruit.y); game.sound('coin'); }
  }
});

// features

Everything around your game, done

The boring 80% is built in, so you spend your evening on the fun 20%.

🎮

Screens & input

Menu, settings, countdown, pause, game over, high score. Keyboard, mouse, touch, swipes and on-screen buttons.

🏃

Objects & camera

Emoji, sprites and shapes with velocity, gravity, collisions, platforms and a smooth follow camera.

🎵

Sound & music

99 sounds — Kenney, ZzFX 8-bit, built-in — plus 5 background tracks. One call: game.sound('coin').

🧙

Sprites

201 Kenney sprites. Characters animate walking and jumping by themselves.

🧲

Physics

physics: true — Matter.js bodies, ropes, collision events and drag-and-throw.

🧊

3D

mode: '3d' — Three.js boxes, spheres, emoji billboards and a chase camera.

🏆

Progression

Levels, lives, an upgrade picker (game.choose) and quizzes (game.ask).

🌍

i18n

English and Russian interface out of the box, every text overridable.

🔷

TypeScript

Typed API, an ES module and a safe SSR import for Next.js and friends.
