GameMonsterJS2D
GitHub

Стек для 2D-игры одной командой

Vite + Phaser 4 + Tiled — команда создаёт папку с игрой и сама ставит все пакеты. Внутри готовый уровень-платформер.

Как начать

  1. Установите Node.js 20.19+ · проверить: node -v
  2. Создайте проект
    npm create gamemonsterjs2d@latest my-game
  3. Запустите
    cd my-game && npm run dev

Откроется на http://localhost:5173, готовая сборка — npm run build → dist/. Пока пакета нет в npm, вместо шага 2: npx github:si0683/GameMonsterJS2D my-game

Что установится

Viteсборка и сервер разработки
Phaser 4сцены, камера, спрайты, ввод, анимации, тайлмапы, звук
ФизикаArcade по умолчанию, Matter.js встроен в Phaser
Tiledуровень level1.tmj, редактор — mapeditor.org
TypeScriptстрогие типы
VK Playчерез GamePush (--sdk=gamepush): VK Play, OK и другие площадки одной сборкой
SDKбез SDK, Яндекс Игры, VK Игры, GamePush, CrazyGames, Poki (--sdk=…)
