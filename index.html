Целая игра в 20 строк

Меню, настройки, отсчёт, пауза, экран «Игра окончена», рекорд и кнопки для телефона уже готовы. Вы описываете только то, что происходит в вашем мире.

  1. 1
    Добавьте две строки

    Стили и скрипт с CDN — ничего не нужно устанавливать.

  2. 2
    Опишите правила

    setup создаёт мир, update выполняется каждый кадр.

  3. 3
    Играйте где угодно

    Откройте файл, выложите на любой хостинг или вставьте в CodePen.

// Ловите фрукты — классическая первая игра
GameMonster.create({
  title: 'Фруктопад', emoji: '🍉', world: 'sky',
  lives: 3, buttons: ['left', 'right'], lang: 'ru',

  setup(game) {
    game.data.hero = game.add({ emoji: '🧺', x: 400, y: 540, size: 70, inside: true });
    game.every(0.7, g => g.add({
      emoji: g.pick(['🍎', '🍌', '🍇']),
      x: g.rand(40, 760), y: -30, vy: 220,
      tag: 'fruit', removeOffscreen: true
    }));
  },

  update(game) {
    const hero = game.data.hero;
    hero.vx = game.key.left ? -500 : game.key.right ? 500 : 0;
    const fruit = game.hitAny(hero, 'fruit');
    if (fruit) { fruit.remove(); game.addScore(1, fruit.x, fruit.y); game.sound('coin'); }
  }
});

Экраны и управление

Меню, настройки, отсчёт, пауза, «Игра окончена», рекорд. Клавиатура, мышь, касания, свайпы и экранные кнопки.

Объекты и камера

Эмодзи, спрайты и фигуры со скоростью, гравитацией, столкновениями, платформами и плавной камерой.

🎵

Звук и музыка

99 звуков — Kenney, 8-битные ZzFX и встроенные — и 5 фоновых мелодий. Один вызов: game.sound('coin').

🧙

Спрайты

201 спрайт Kenney. Персонажи сами анимируют ходьбу и прыжки.

🧲

Физика

physics: true — тела Matter.js, верёвки, события столкновений, бросок мышью.

🧊

3D

mode: '3d' — кубы и сферы Three.js, эмодзи-спрайты и камера за героем.

🏆

Прогресс

Уровни, жизни, выбор улучшений (game.choose) и викторины (game.ask).

🌍

Два языка

Интерфейс на русском и английском, любую надпись можно заменить.

🔷

TypeScript

Типизированный API, ES-модуль и безопасный импорт при серверном рендеринге в Next.js.
