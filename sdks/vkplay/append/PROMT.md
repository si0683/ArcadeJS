## 10. Платформа: VK Play

Проект создан с JS API VK Play (`--sdk=vkplay`). Прочитай `VKPLAY.md`. Номер игры (GMRID) — в `.env`.

- **Покупки:** «товары, цена в рублях» (цены — в `VKPLAY_PRODUCTS` в `src/platform/vkplay.ts`, id совпадают с `PRODUCTS`)
- **Проверка оплаты на сервере:** [ ] не нужна (только «Убрать рекламу») [ ] нужна: уведомления о платежах VK Play принимает мой сервер
- **Реклама:** [ ] если VK Play включит её для игры [ ] не нужна
- **Сохранения:** «что сохранять» (localStorage игры; облачных сохранений в JS API VK Play нет)

Все вызовы API — только через `platform` из `src/platform`. Новые возможности сначала добавь в интерфейс `Platform`.
