# VK Play

Проект создан с `--sdk=vkplay`. Игра работает с собственным JS API площадки [VK Play](https://vkplay.ru), без сторонних SDK и посредников.

Документация: https://documentation.vkplay.ru — раздел «JS API integration» ([PDF](https://documentation.vkplay.ru/hotbox/devdocs/pdfcopy/en/1119.pdf)).

## Что подключено

| Что                                | JS API VK Play                                                                                                                             | В игре                                                      |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------- |
| Подключение                        | скрипт `vkplay.ru/app/<GMRID>/static/mailru.core.js` и `window.iframeApi(callbacks)`                                                       | `platform.init()` в `src/main.ts` до старта Phaser          |
| Статус игрока                      | `getLoginStatus()` → `getLoginStatusCallback` (0 — не вошёл, 1 — вошёл, но не зарегистрирован в игре, 2 — зарегистрирован, 3 — купил игру) | перед покупкой                                              |
| Вход и регистрация                 | `authUser()` (окно входа, затем страница перезагружается), `registerUser()` (окно правил) → `registerUserCallback`                         | перед покупкой, если нужно                                  |
| Покупки                            | `paymentFrame({ merchant_param: { amount, currency, description, item_id } })` → `paymentReceivedCallback` / `paymentWindowClosedCallback` | `shop` из `src/shop.ts`; на время окна оплаты игра на паузе |
| Сохранения                         | в JS API нет                                                                                                                               | localStorage в рамке игры                                   |
| Лидерборд, «игра готова», геймплей | в JS API нет                                                                                                                               | ничего не делают                                            |
| Язык                               | в JS API нет                                                                                                                               | язык браузера                                               |
| Реклама                            | в открытой документации нет                                                                                                                | только если у объекта API есть `showAds` (см. ниже)         |

Без номера игры, вне VK Play или если скрипт не загрузился, игра работает как без SDK: localStorage, без рекламы и покупок. Поэтому `npm run dev` работает сразу.

## Настройка

1. Создайте браузерную игру в кабинете разработчика VK Play и узнайте её номер — **GMRID**.
2. Скопируйте `.env.example` в `.env` и впишите номер: `VITE_VKPLAY_APP_ID=12345`.
3. **Цены** — в `VKPLAY_PRODUCTS` в `src/platform/vkplay.ts`, в рублях: `no_ads: { title: "Убрать рекламу", amount: 99 }`. Id совпадают с `PRODUCTS` в `src/shop.ts`. Каталога товаров для окна оплаты у VK Play нет, цену передаёт игра. Разовые товары (монеты) игра выдаёт и расходует сама (`createShop(platform, { coins_100: … })`).
4. **Проверка оплаты.** VK Play сообщает о платежах серверу разработчика (уведомления о платежах — в документации VK Play). Купленные постоянные товары игра помнит в браузере игрока. Если товар ценный или должен переноситься между устройствами, принимайте уведомления на своём сервере и выдавайте товар по ним.
5. `npm run zip` → `game.zip` загрузите в кабинет.

## Реклама

В опубликованной документации JS API рекламы нет. В части игр на VK Play у объекта API есть метод `showAds({ interstitial })`, а площадка отвечает в `adsCallback` событиями `adCompleted`, `adDismissed`, `adError`. Игра использует этот способ, только если метод действительно есть (`platform.features.ads`), иначе реклама просто не показывается и игра не ломается. Включена ли реклама для вашей игры, уточните в поддержке VK Play.

## Проверка

```bash
npm run dev      # без номера игры: режим без SDK
npm run build && npm run zip
```

Браузерные тесты подставляют поддельный `mailru.core.js` (`e2e/sdk-mock.ts`): с `VITE_VKPLAY_APP_ID=1 npm run test:e2e` проверяется подключение API, окно оплаты и пауза.
