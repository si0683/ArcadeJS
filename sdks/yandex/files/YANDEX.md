# Яндекс Игры

Проект создан с SDK Яндекс Игр (`--sdk=yandex`). Код игры обращается только к `platform` из `src/platform`; вызовы SDK собраны в `src/platform/yandex.ts`.

Документация SDK: https://yandex.ru/dev/games/doc/ru/sdk/sdk-about

## Что уже подключено

| Что | Метод SDK | Где в игре |
|---|---|---|
| Загрузка SDK | `/sdk.js` + `YaGames.init()` | `platform.init()` в `src/main.ts` до старта Phaser |
| Игра готова | `features.LoadingAPI.ready()` | `PreloadScene` после загрузки ресурсов |
| Начало и конец игры | `features.GameplayAPI.start()` / `stop()` | старт уровня / победа и проигрыш |
| Пауза платформы | события `game_api_pause` / `game_api_resume` | `src/main.ts`: звук выключается, игра замирает |
| Реклама между раундами | `adv.showFullscreenAdv()` | после победы или проигрыша, перед меню |
| Реклама за награду | `adv.showRewardedVideo()` | `platform.showRewardedAd()` — подключите сами, пример ниже |
| Сохранения | `player.getData()` / `setData()` | рекорд в облаке игрока (+ копия в localStorage) |
| Лидерборд | `leaderboards.setScore()` | рекорд в конце игры, лидерборд `score` |
| Покупки | `getPayments()`: `getCatalog`, `purchase`, `getPurchases`, `consumePurchase` | `src/shop.ts`: кнопка «Убрать рекламу» в меню |
| Язык | `environment.i18n.lang` | `content/i18n/*.json` — русский или английский |

## Проверка

```bash
npm run dev      # без SDK: /sdk.js нет (404 и предупреждение в консоли — это нормально), игра работает в режиме «без SDK»
npm run yandex   # сборка + @yandex-games/sdk-dev-proxy в dev-окружении: настоящий SDK, вместо рекламы заглушки
```

`npm run yandex` откроет игру на `https://localhost:8080`. Браузер предупредит о сертификате — это локальный адрес, продолжите.

В боевом окружении, с настоящей рекламой и входом через Яндекс ID, игра открывается так:

```bash
npm run build
npx @yandex-games/sdk-dev-proxy -p dist --app-id=<ID черновика>
```

Подробнее: https://yandex.ru/dev/games/doc/ru/concepts/local-launch

## Публикация

1. Соберите архив командой `npm run zip`. Получится `game.zip` с `index.html` в корне.
2. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console), создайте черновик игры и загрузите `game.zip`.
3. На вкладке «Лидерборды» создайте лидерборд с техническим именем `score`. Имя задаётся константой `LEADERBOARD` в `src/platform/yandex.ts`.
4. Откройте черновик с debug-панелью: кнопка «Открыть с debug-панелью» или `?debug-mode=16` в адресе. Индикатор лоадера слева внизу должен показывать `IT`.
5. Отправьте игру на модерацию.

## Покупки

Пример в шаблоне — постоянная покупка **«Убрать рекламу»** (`no_ads`): после неё реклама между раундами не показывается. Покупки читаются из SDK при каждом запуске (`shop.restore()`), поэтому не теряются при смене устройства.

1. В Консоли включите покупки: вкладка «Покупки» → подключение (нужен договор и одобрение Яндекса). Пока покупки не одобрены, `getPayments()` не работает и кнопка покупки не показывается.
2. Создайте товар с идентификатором `no_ads` — тем же, что в `PRODUCTS` в `src/shop.ts`. Название и цена в меню берутся из Консоли.
3. Свой товар:
   - **постоянный** (скин, уровни, без рекламы) — id в `PRODUCTS`, проверка `shop.has(id)`;
   - **расходуемый** (монеты, жизни) — функция выдачи в `createShop(platform, { coins_100: () => … })`. Магазин выдаст товар и вызовет `consumePurchase`, а оплаченный, но не выданный (закрыли вкладку) выдаст при следующем запуске.
4. Проверка: `npm run yandex` — в dev-окружении покупки тестовые, деньги не списываются.

Документация: https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases

## Реклама за награду

```ts
import { platform } from "../platform"

const rewarded = await platform.showRewardedAd()
if (rewarded) {
  this.registry.inc("lives", 1) // награда — только если реклама досмотрена
}
```

Показывайте рекламу только в логических паузах (меню, конец уровня), не во время игры. Частоту полноэкранной рекламы ограничивает сама платформа.

## Требования модерации

Самое частое, что проверяют (полный список: https://yandex.ru/dev/games/doc/ru/concepts/requirements):

- [x] Вызывается `LoadingAPI.ready()`, язык берётся из SDK.
- [x] Звук и игра останавливаются при сворачивании вкладки и во время рекламы.
- [x] Нет прокрутки страницы, выделения и контекстного меню по долгому тапу (`index.html`).
- [x] Архив: `index.html` в корне, пути относительные.
- [ ] Прогресс сохраняется сразу после действия игрока: вызывайте `save.update()` из `src/save.ts` (он объединяет рекорд и настройки и пишет через `platform.saveData()`).
- [ ] Никаких ссылок на внешние сайты: свой сайт, магазины, соцсети.
- [ ] Игра полностью управляется касаниями на телефоне и работает на всех платформах, выбранных в черновике.
- [ ] Размер игры в распакованном виде — до 100 МБ, имена файлов без пробелов и кириллицы.

## Убрать SDK

В `src/platform/index.ts` замените `"./yandex"` на `"./none"`. Остальной код менять не нужно.
