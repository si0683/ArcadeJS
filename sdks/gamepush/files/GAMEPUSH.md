# GamePush: VK Play и другие площадки

Проект создан с `--sdk=gamepush`. [GamePush](https://gamepush.com) — один SDK для многих площадок: **VK Play**, VK Игры, Одноклассники, Яндекс Игры, CrazyGames и других. SDK сам определяет площадку по адресу, где запущена игра, поэтому одна сборка работает везде, где вы подключили GamePush. У VK Play нет открытого JS SDK для HTML5-игр, поэтому GamePush — самый короткий путь туда.

Документация: https://docs.gamepush.com/ru/docs/get-start/ · справочник методов: https://gamepush.com/sdk/docs/

## Что уже подключено

| Что | GamePush | В игре |
|---|---|---|
| Загрузка SDK | `game-score.js?projectId=…&publicToken=…&callback=onGPInit` (4 зеркала, как в официальном загрузчике) | `platform.init()` в `src/main.ts` до старта Phaser, ждёт `gp.player.ready` |
| Игра готова | `gp.gameStart()` | `PreloadScene` после загрузки ресурсов |
| Геймплей | `gp.gameplayStart()` / `gp.gameplayStop()` | начало уровня, пауза, конец уровня |
| Пауза площадки | события `pause` / `resume` (реклама, свёрнутая вкладка) | `src/main.ts`: звук выключается, игра замирает |
| Реклама между раундами | `gp.ads.showFullscreen()` | конец уровня (если не куплено «Убрать рекламу») |
| Реклама за награду | `gp.ads.showRewardedVideo()` → `true`, если досмотрел | `platform.showRewardedAd()` |
| Сохранения | поле игрока `save` (строка с JSON) + `gp.player.sync()` | `save.update()` из `src/save.ts` |
| Лидерборд | поле игрока `score` | `platform.submitScore()` в конце уровня — только если результат лучше |
| Покупки | `gp.payments.purchase/consume/products/purchases` по **тегу** товара | `shop` из `src/shop.ts` |
| Язык | `gp.language` | `src/i18n.ts` |

Без ключей проекта или если SDK не загрузился, игра работает как без SDK: localStorage, без рекламы. Поэтому `npm run dev` работает сразу.

## Настройка (один раз)

1. Зарегистрируйтесь на https://gamepush.com и создайте проект в панели управления.
2. **Ключи:** скопируйте `.env.example` в `.env` и впишите «ID проекта» и «Публичный ключ» из публичной зоны проекта:
   ```
   VITE_GAMEPUSH_PROJECT_ID=12345
   VITE_GAMEPUSH_PUBLIC_TOKEN=…
   ```
   Публичный ключ попадает в сборку — это нормально, он для этого и нужен.
3. **Поле для сохранений:** панель → «Игроки» → добавьте поле `save`, тип «Строка» (String). Без него сохранения остаются в localStorage браузера (в консоли будет предупреждение).
4. **Лидерборд:** панель → «Лидерборды» → создайте таблицу по полю `score`.
5. **Покупки:** панель → «Покупки» → создайте товары. **Тег** товара должен совпадать с id в `PRODUCTS` в `src/shop.ts` — например, `no_ads` для «Убрать рекламу». Разовые товары (монеты) игра расходует сама после выдачи.
6. **Площадки:** в панели подключите нужные площадки (VK Play и другие) и следуйте их шагам публикации в документации GamePush.

## Проверка

```bash
npm run dev       # без .env — как без SDK; с .env — с настоящим SDK GamePush
npm run check     # линтер, типы, тесты, сборка
npm run test:e2e  # браузерная проверка с поддельным SDK (e2e/sdk-mock.ts)
```

Чтобы браузерная проверка шла с поддельным GamePush, задайте ключи (любые) в `.env` или в переменных окружения перед `npm run test:e2e`.

## Публикация

```bash
npm run zip       # game.zip с index.html в корне
```

Архив загружается в панель GamePush или на площадку — по инструкции GamePush для конкретной площадки. Требования модерации у каждой площадки свои (VK Play: исключительные права на игру, стабильная работа, локализация); проверьте их до отправки.

## Правила

- Код игры не обращается к `gp` напрямую — только к `platform` из `src/platform`. Новую возможность GamePush (достижения, лидерборд с наградами, облачные переменные) сначала добавьте в интерфейс `Platform` (`types.ts`, `none.ts`, все SDK), потом используйте.
- Рекламу показывайте только в паузах между раундами, за награду — только по кнопке игрока.
