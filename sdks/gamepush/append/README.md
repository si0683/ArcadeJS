
## GamePush: VK Play и другие площадки

Проект создан с SDK GamePush — одна сборка для VK Play, VK Игр, Одноклассников, Яндекс Игр и других площадок. Ключи проекта — в `.env` (образец — `.env.example`), настройка и публикация — в [GAMEPUSH.md](GAMEPUSH.md).

```bash
npm run zip      # game.zip для панели GamePush / площадки
```
